# OdinLandingPage

Project Overview

This is a flexbox landing page project created as part of The Odin Project curriculum. The design implements modern web development principles with a clean, professional layout that adapts to different screen sizes.

💻 Technologies Used

    HTML5 - Semantic markup
    CSS3 - Styling and animations
    Flexbox - Layout system
    Media Queries - Responsive design
    CSS Variables - Consistent styling

🚀 Installation & Usage

    Clone or download the project files
    Open index.html in your web browser
    No additional dependencies or build steps required
